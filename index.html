Format TXT

When on, Format also tidies the output after beautifying it — what that means depends on the file type:

  • Plain text — every blank line is removed and trailing spaces are trimmed from each line.
  • Markdown — trailing spaces are trimmed, and runs of multiple blank lines are collapsed down to one, so paragraph and list breaks are kept.
  • CSV, TSV — leading and trailing whitespace is trimmed from every cell.
  • JSON, XML, YAML, TOML, HTML, SQL, GraphQL — these are already rebuilt from scratch when formatted, so there are no stray blank lines or trailing spaces to clean up either way.

Turn it off to keep the output exactly as formatted, blank lines included.

  • JSON
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    [
  { "name": "Alice", "age": "30" }
]
    
      
    • 
      
  • YAML
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    - name: Alice
  age: '30'
    
      
    • 
      
  • XML
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    <root>
  <row>
    <name>Alice</name>
    <age>30</age>
  </row>
</root>
    
      
    • 
      
  • TOML
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    [[items]]
name = "Alice"
age = "30"
    
      
    • 
      
  • CSV
        Accepts input like:
        
    {"name": "Alice", "age": 30}
    
        Converts to:
        
    name,age
Alice,30
    
      
    • 
      
  • TSV
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    name␉age
Alice␉30
    
      
    • 
      
  • Excel (XLSX)
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    Downloads as a real .xlsx workbook, with "name" and "age" as column headers
    
      
    • 
      
  • PDF
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    Downloads as a real .pdf document, with the data laid out as plain monospaced text
    
      
    • 
      
  • Markdown
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    | name | age |
| --- | --- |
| Alice | 30 |
    
      
    • 
      
  • HTML
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    <table>
  <tr><th>name</th><th>age</th></tr>
  <tr><td>Alice</td><td>30</td></tr>
</table>
    
      
    • 
      
  • SQL
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    INSERT INTO my_table (name, age)
VALUES ('Alice', 30);
    
      
    • 
      
  • GraphQL
        Accepts input like:
        
    name,age
Alice,30
    
        Converts to:
        
    query {
  items {
    name
    age
  }
}
    
      
    • 
      
  • Plain text (TXT)
        Accepts input like:
        
    {"name": "Alice"}
    
        Converts to:
        
    {"name": "Alice"}
    
      
    • 
    


    
Any format can be converted to any other using the Convert menu — every conversion produces both a copyable text preview and a downloadable file. SQL and GraphQL conversions are best-effort, since they aren't natural tabular formats.

  


  

    

      
    

    

      
      
    

    

      
      
    

    
    

  


  

    

      Privacy Policy
      
    

    
Your data stays yours. Everything you paste, upload, beautify, or convert on Data Ekam runs entirely in your browser — nothing you type or upload is ever sent to, stored on, or logged by our servers.

    
    
      
  • No file storage — files you drop or upload are read locally by your browser and never uploaded anywhere.
    • 
      
  • No content logging — pasted text, beautified output, and converted files are not recorded or transmitted.
    • 
      
  • Feedback is opt-in — the only information we ever receive is what you type into the feedback form, and only when you press submit.
    • 
      
  • Advertising cookies need your consent — if Google Ads is used on this site, ad personalization and tracking cookies are only set after you accept the cookie banner. Decline and the site works exactly the same, just without personalized ads.
    •

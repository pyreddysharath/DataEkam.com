Contact

Bug reports, wrong conversions and feature requests are all welcome.

Send feedback from the tool

The quickest route is the feedback form built into Data Ekam. Open the tool's feedback form (the speech-bubble icon at the bottom of the main page), enter your name and a message, and press Send Feedback. Nothing from the input box is attached, so include any detail we need in the message itself.

Report a bug on GitHub

The source code for this site is public. If you have a GitHub account, you can open an issue in the Data Ekam repository. This is the best place for bugs, because you can follow the fix and other people can add examples.

What helps us fix a problem

  • What you did. Which tab you were on, the format you chose under Format or Convert, and whether Clean was ticked.
  • A small sample. The shortest input that still shows the problem. Please replace real names, keys and passwords with made-up values first.
  • What you expected and what you got. A wrong output is much easier to fix when we can see the right one beside it.
  • Your browser and device. For example, Chrome on Android or Safari on a Mac.

Things we cannot help with

Because everything is processed in your browser, we never receive the data you paste or upload. That means we cannot recover text you cleared, resend a file you converted, or look up a previous session. If you need to keep a result, use Copy or Download before closing the page.

Privacy and advertising questions

Questions about cookies, advertising or how the site handles information are answered in the privacy policy. You can change your cookie choice at any time from the cookie icon at the bottom of the main page.

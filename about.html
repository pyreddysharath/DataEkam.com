About Data Ekam

One place to format, convert and compare everyday data, without sending that data anywhere.

What Data Ekam is

Data Ekam is a free web tool for people who handle structured text: developers, analysts, testers, students and anyone who has ever been handed a file in the wrong format. It does three jobs. It formats messy JSON, YAML, XML, TOML, CSV, TSV, Markdown, HTML, SQL, GraphQL and plain text so it is readable. It converts between those formats and can also produce real Excel workbooks and PDF files. And it compares two pieces of text line by line so you can see exactly what changed.

Most sites that do these things do one of them per page, so a simple task turns into three tabs and three uploads. Data Ekam keeps all of it on one screen with one input box.

What the name means

"Ekam" (एकम्) is the Sanskrit word for "one". The name is pronounced DAY-tuh AY-kum. It describes the idea behind the site: one tool, one page and one input for the many formats that data moves through. The logo is two loops meeting at a single point, which can be read as a D and an E.

How it works

Everything runs in your browser. When you paste text or drop a file into Data Ekam, the parsing, formatting, conversion and comparison are done by JavaScript on your own device. Your content is not uploaded to a server, because there is no server-side processing to upload it to. That matters when the data is a customer export, a configuration file with internal hostnames, or anything else you would rather not hand to a third party.

Working this way has a practical limit, which we would rather state than hide: the input box accepts up to 1,000,000 characters, and very large files depend on how much memory your browser has available.

The tool relies on three well-known open-source libraries, loaded from a public CDN: SheetJS for reading and writing Excel workbooks, js-yaml for YAML, and jsPDF for building PDF files. The remaining parsers and formatters, and the comparison view, are written for this site.

What we try to get right

  • You choose the format. Data Ekam does not guess what your input is. Guessing fails on exactly the inputs that are broken, which are the ones people bring to a formatter. You pick the format and the tool tells you where the text stops being valid.
  • Errors say where. When input cannot be parsed, the message includes the line and position, and the line is highlighted in the input box.
  • Conversions do not silently lose data. JSON, YAML and XML are converted structure to structure, so nesting survives. Where a conversion can only be approximate, as with SQL and GraphQL, the tool says so.
  • Output you can use. Every result can be copied as text or downloaded as a file. Excel and PDF downloads are real .xlsx and .pdf files.

How the site is funded

Data Ekam is free to use and has no accounts, paid tiers or usage limits. It is intended to be supported by advertising through Google. Advertising cookies are only set if you accept them in the cookie banner; if you decline, the tool works in exactly the same way. The details are in the privacy policy.

Who runs it

Data Ekam is an independent project. The same people also build and maintain a small family of free sites: AyuBase6.com, a personal health companion; BharatGaruda.com, a directory of Indian government links organised by state; IntiGuttu.com, a searchable home reference for kitchen tips, remedies and recipes; and RummyTally.com, a rummy scoreboard.

If something is broken, confusing or missing, we would like to hear about it. The contact page explains how to reach us.
